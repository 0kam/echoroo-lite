## 提案 A：種のページを「2 つの問いと、その答え」にする

ページの目的を 1 つに決める：**この種について、2 つの問いに答える。**

- ① この地点で、この種の声はあったか
- ② いつ・どれくらい鳴いたか

### 並べ方

- 2 つの問いを、番号の付いた手順として縦に並べる。
- **今やる手順だけを開く。** そこに説明 1〜2 文と主ボタンを 1 つ置く。ページ全体で、主ボタンは常に 1 つにする。
- 終わった手順は 1 行の答えに縮める（例：「✓ 声があった（3 音を確かめた）」）。
- まだの手順は 1 行で示し、副ボタンを 1 つ置く。①の前に②をしたい人のため。
- 2 つとも答えが出たら、「この種でやることは終わりです」と［種の一覧に戻る］を出す。レポートへ載せる道は、一覧（地点の結果）にある。

### 今やる手順の決め方

| 状態 | 開く手順 | 主ボタン |
|---|---|---|
| ①まだ | ① | ［聞いて確かめる］ |
| ①声あり、②まだ | ② | ［AIの答えを確かめる］ |
| ②の途中 | ② | ［続きを答える（24 / 60）］ |
| ②境目が決まった | なし（終わり） | ［種の一覧に戻る］ |
| ②境目が決まらなかった | ② | ［この種だけを探すAIを育てる］（副：［ここで終える］） |
| ①見つからなかった | なし（終わり） | ［種の一覧に戻る］（副：［お手本の声に似た音を探す］） |

### いまの部品の行き先

これで、前回の判断待ち「『聞こえる』が証拠になることの伝え方」にも答える。

### 「育てる」の出し方

育てるのは、②「いつ・どれくらい」に答えるための手段なので、いつも②の中に出す。

| 場面 | ②での出方 | 見本 |
|---|---|---|
| ②の境目が決まらなかった | 主ボタン［この種だけを探すAIを育てる］と［ここで終える］ | 場面 5 |
| AI の一覧にない種 | ①はお手本の声で探して確かめる。そのあと②に「この種を聞き分ける AI がないので、あなたの答えで育てます」と主ボタン | 場面 7・8 |
| AI がこの種の音を 1 つも見つけていない | 上と同じ形。①でお手本の声で探し、「声あり」が見つかったら②で育てる | 場面 7・8（文だけ違う） |
| この種用の AI がすでにある | ②の AI の 1 つとして並べる。まだ育てている途中なら、そこに［続けて育てる］（主ボタン） | 場面 9 |

出さない場面：

- ②の境目が決まったとき。答えが出ているため。
- ①で見つからなかったとき。上位の音に声がなかったので、育てても材料の「声あり」が集まりにくいため。①の［お手本の声で探す］で声が見つかれば、①が「声あり」に変わり、②で育てられる。
- AI の一覧にない種・AI の検出がない種で、①がまだのとき。育てる画面は、お手本の声で探した結果がないと音を選べない（今の育てる画面と同じ）。先に①をする。

育てる画面に入ってからの条件（声あり・声なしが 3 音ずつ、合わせて 20 音でAIを作る）は今のまま。

- 地点の画面の「音の地図（実験的）」：別の入口で、この提案の外に置く。

## 提案 B：言葉の決め事

決め事は 3 つ。

1. 言い換えられる言葉は言い換える。
2. 言い換えられない名前（AI の名前など）は、その画面で最初に出る所に、1 行の説明をその場に書く。カーソルを重ねて出す説明にはしない。
3. 画面では「AI」だけを使い、「モデル」は使わない。

| 言葉（日本語の文に出る回数） | 案 | 例 |
|---|---|---|
| 区間（53） | 「音」に統一する | 「5 秒ごとの音」「1,200 音で検出」「まだ解析していない時間」 |
| スコア（39） | 「AI の点数」に言い換え、初出に 1 行 | 「AI の点数（0〜1。高いほど、この種の声らしいと AI が見ている）」 |
| 閾値（17） | 「境目」 | 「AI の点数 0.62 以上を『声あり』と数えます。この境目は、あなたの答えで決まりました。」 |
| モデル（29） | 「AI」 | 「モデルごとの時間の図」→「どの AI の図か」 |
| メル／線形 | 名前を変えて残す | 「低い音を広く」／「高い音も同じ幅」 |
| kHz | 軸の名前を足す | 「音の高さ（kHz）」 |
| 日付 → 外側 | 文にする | 「内側が最初の日、外側が最後の日」 |
| 未解析・対象区間なし | 言い換え | 「まだ解析していない」 |
| Perch V2・BirdNET | 名前は残し、初出に 1 行 | 「Perch V2（Google が作った、鳥などの声を聞き分ける AI）」 |
| 地鳴き・さえずり | 初出に 1 行 | 「さえずり：主に繁殖期の長い歌。地鳴き：一年中聞かれる短い声。」 |
| 質 A〜E | 言い換え | 「録音の質（A がいちばん良い）」 |
| 一般名 | 言い換え | 「名前（和名など）」 |
| 参照音・参照区間 | 「お手本の音」に統一 | |

- レポート（`apps/sidecar/data/report/messages.json`）と README の方法の説明も、同じ決め事にそろえる。CSV の列名は変えない。読み込む側が困るため。
- 英語の画面も同じ考えで直す（score → "AI score" と説明 1 行、threshold → "cut-off"、interval/window → "clip"）。
- 使われていない古い文（`i18n.ts` の `rawScores`・`candidateWindows` など）は、実装のときに使われていないことを確かめて消す。

## 決めてほしいこと

1. 提案 A の並べ方（今やる手順だけを開き、主ボタンを 1 つにする）でよいか。
2. 「スコア」は「AI の点数」に言い換えるか、「スコア」のまま初出に説明を付けるか。おすすめは言い換え。
3. 「この種用のAIを育てる」を、必要なときだけ出すことにしてよいか。おすすめは、必要なときだけ。
4. メル／線形の切り替え：名前を変えて残すか、消すか。おすすめは残す。セミなど高い声の種では、線形のほうが見やすいため。

前回からの判断待ち（この提案の外）：

- クイズに最初から入っている音がない件。
- 人が確かめたのにレポートに載せていない種の名前を並べるか。
