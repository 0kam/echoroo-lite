# 学習クイズの実装（2026-09-08）

## 使い方

録音群を作る前でも「鳴き声クイズ」を開ける。初期セットは、指定された
`../koe-e-lab/sample_data` の26種・26音源と写真をそのまま同梱したもの。
「種・音源を選択」で出題候補を選び、名前を付けて問題セットとして保存できる。
2種以上を選ぶと、その中から音源を同じ重みで無作為に出題する。
1回1〜50問、同じ音源の重複なし。候補が少ない場合は実際の音源数まで出題する。
同じ種に複数音源がある場合、その種の出題機会も増える。

回答は最大4種の選択肢と「わからない」。回答前は正解、写真、元のファイル名、
解説を表示しない。回答後に登録された正解、写真、声の種類、メモ、出典を表示し、
必要ならスペクトログラムを開ける。最初の回答だけを保存し、正解・誤答・不明を
区別する。終了後は種別の内訳と再試聴、途中の場合は履歴から再開できる。
履歴の一覧は直近50回。より古い履歴もDBから消さない。

## オリジナル音源と区間の追加

「音源から問題を追加」で正解にする種を選び、手元の WAV / FLAC / MP3、
選択中の録音、または取得済みの Xeno-Canto 音源を指定する。
スペクトログラムをドラッグするか秒数を入力し、0.2〜60秒の区間を選択・試聴する。
声の種類、回答後のメモ、任意の出典を添えて保存する。

保存時に選択部分だけをモノラル32 kHz・FLOAT WAVとしてアプリ内へコピーする。
ステレオは左右平均。元音源の登録情報、区間、SHA-256、種ID、XCの出典情報を保持する。
元ファイルを移動・削除しても保存済み問題の再生は影響を受けない。
既存のクイズ素材から別区間を選ぶ場合も新しい問題となり、元の問題や回答は変えない。
出題を止める「休止」は履歴と音源を削除しない。休止中の問題は新規出題から除く。

## 保存と品質の境界

- `quiz_clips` に素材と正解種、`quiz_sets` に名前と素材ID集合を保存する。
  `quiz_sessions` は出題した素材・選択肢・名前・出題方式のスナップショットと初回答を持つ。
- 初期MP3も初回利用時に `<data>/quiz/audio` へコピーする。
  凍結実行ファイルの一時展開先を永続データとして参照しない。写真は同梱キーで解決する。
- これは繰り返し学習するためのクイズ。成績を未見音源の同定能力、現地の検出品質、
  precision / recall や報告の補正重みに変換しない。「わからない」を分母から除かない。
- 初期の正解種・声の種類は提供されたファイル名から対応付けた。
  岡本による全区間の確認が完了したと扱わない。評価用の未見問題や専門家による承認、
  音量変更・混合、能力補正は今回の学習機能に含めていない。

## 素材の由来

再生成は `python scripts/bundle_quiz.py`。入力は
[quiz-source-inventory.csv](quiz-source-inventory.csv)、出力は
`apps/sidecar/data/quiz/manifest.json` と26 MP3・26 JPEG（合計約8.8 MB）。
元バイト列を保持し、音声・写真のハッシュを記録する。シルエット素材は使用していない。

キジは `Phasianus versicolor`。BirdNETの `Phasianus colchicus`（コウライキジ）に
付け替えず、Perch側に既にある種IDに日英名を補う。
ムクドリMP3のID3にある録音者 `Anon Torimi` とXC番号 `510632` を引き継いだ。
それ以外の出典・撮影者・利用条件は個別対応が未確認で、UIでは「未登録」とする。
所有者やライセンスを推測して埋めない。素材情報はユーザーに確認中。

## 検証

- APIテスト: 26種の初期登録、音声・写真、初回答の固定、正誤／不明、途中再開、
  区間コピーと元音源削除後の再生、再切り出し時の出典継承、問題セット、休止・再開、
  DB再起動後の履歴保持を確認。
- 開発画面: 日英の出題・回答・写真・結果、3問の途中再開、ウグイスとキジのセット保存、
  ウグイス音源の画面ドラッグによる区間指定と9〜12秒の保存を確認。
- 凍結サイドカー: 26種を同梱した状態の出題・MP3取得・不明回答保存を確認。
  同じ実行ファイルで30分実音源の解析57.86秒、検索・報告書き出し、正常終了も確認した。
- Mac開発アプリ: 26種の初期セット、ウグイスの出題・音声、回答後の写真、
  スペクトログラムと選択区間再生、日英の結果表示を確認。Python7件とSvelte検査
  （エラー0・警告0）が通過し、最終ビルドと凍結版のクイズ疎通も成功した。
- Mac配布アプリ: 手元のMP3をネイティブダイアログで選び、9〜12秒を新規問題に保存。
  初期26種セットは変更せず、独立した3秒音声を保持した。終了・再起動後も初期セットと
  既存の学習結果を表示できた。保存先は開発環境ではなくアプリのデータフォルダ。
  復習の「聴く」は押すと再生し、再度押すと先頭へ戻る。配布版で再生中表示・経過11秒から
  0秒への復帰・問題選択への移動によるプレイヤー終了を確認した。

Windowsでの音声・写真・ファイル選択と配布版の受け入れは別途必要。
