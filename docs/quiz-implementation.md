# 学習クイズの実装（2026-10-26更新）

2026-10-26 の合意により、クイズ用の音源はアプリに同梱しない。
野山・水辺の2セット、manifest v3、CSVによる同梱素材の選定は取り下げた。
クイズ機能は残し、利用者が自分の録音や Xeno-Canto の音源を追加して使う。

## 使い方

録音群を作る前でも「鳴き声クイズ」を開ける。初回は問題がないため、
「クイズに使う鳴き声を追加」から音源を登録する。
出題候補を選び、名前を付けて問題セットとして保存できる。
2種以上を選ぶと、その中から音源を同じ重みで無作為に出題する。
1回1〜50問、同じ音源の重複なし。候補が少ない場合は実際の音源数まで出題する。
同じ種に複数音源がある場合、その種の出題機会も増える。

回答は最大4種の選択肢と「わからない」。回答前は正解、元のファイル名、
解説を表示しない。回答後に登録された正解、声の種類、メモ、出典・録音者・ライセンスを表示し、
必要ならスペクトログラムを開ける。最初の回答だけを保存し、正解・誤答・不明を
区別する。終了後は種別の内訳と再試聴、途中の場合は履歴から再開できる。
履歴の一覧は直近50回。より古い履歴もDBから消さない。

## 音源と区間の追加

`/quiz/add` で正解にする種を選び、手元の WAV / FLAC / MP3、選択中の録音、
または取得済みの Xeno-Canto 音源を指定する。Xeno-Canto の検索・取得には利用者自身のAPIキーを使う。
スペクトログラムをドラッグするか秒数を入力し、0.2〜60秒の区間を選択・試聴する。
声の種類、回答後のメモ、任意の出典を添えて保存する。

保存時に選択部分だけをモノラル32 kHz・FLOAT WAVとして `<data>/quiz/audio` へコピーする。
ステレオは左右平均。元音源の登録情報、区間、SHA-256、種ID、XCの出典情報を保持する。
元ファイルを移動・削除しても保存済み問題の再生は影響を受けない。
既存のクイズ素材から別区間を選ぶ場合も新しい問題となり、元の問題や回答は変えない。
出題を止める「休止」は履歴と音源を削除しない。休止中の問題は新規出題から除く。

## 保存と品質の境界

- `quiz_clips` に素材と正解種、`quiz_sets` に名前と素材ID集合を保存する。
  `quiz_sessions` は出題した素材・選択肢・名前・出題方式のスナップショットと初回答を持つ。
- `/quiz/library` は利用者の素材・セット・履歴を返す。同梱素材の初期登録は行わず、
  セットに v2 用の `set` フィールドを追加しない。
- 過去の開発版が登録した `koe-e-lab-v1` と `xeno-canto-v1` の素材は利用停止にし、
  セットの `bundled_key` を解除する。保存済み音声、セット、回答、出題スナップショットは削除しない。
  過去のセッションの成績は表示できるが、旧同梱素材の音声・画像は提供しない。
- これは繰り返し学習するためのクイズ。成績を未見音源の同定能力、現地の検出品質、
  precision / recall や報告の補正重みに変換しない。「わからない」を分母から除かない。
  正解種は利用者が指定する。専門家による承認や独立した能力評価を示すものではない。

## 検証

- `test_quiz.py` は利用者の音源登録APIから素材を追加し、出題、初回答の保持、再開、
  音声・スペクトログラム、出典の継承、休止、旧2系列の履歴保持と再生停止を検証する。
  例示・レポートのテストも利用者が追加した素材を使う。
- CIの実音声ML検証には `scripts/fixtures/horornis-diphone-xc1177906.mp3` の1本だけを使う。
  帰属は同じフォルダの `README.md` に記録し、アプリには同梱しない。
  出題には2種以上が必要なので、1種だけのCI音声から架空の問題は作らず、出題検証は省く。
- Windowsのインストール検証では空のクイズページが開くことだけを確認する。
  実機UIの使いやすさはAPIテストとは別に確認が必要。
