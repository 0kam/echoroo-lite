# HTMLレポートの実装（2026-09-13）

ユーザーのPDF必須の撤回とHTML主体への提案を受け、本文・表・図・音声を一つのHTMLから参照する形へ実装した。DOCX生成は追加せず、本文・表のコピーと図の画像保存を使う。転記に不足があればDOCXを再検討する。

## 操作と内容

地点の結果 →「レポートを書き出す」→ 保存先を選ぶ →「レポートを開く」。掲載種の初期値は一覧の全種で、必要なら収録種を変えられる。保存先と収録種は戻る操作で保持する。形式・モデル・閾値の追加選択は置かない。

保存先には閲覧用フォルダと同じ内容のZIPを作る。本文・表はHTMLの文字と表で、Word等への転記用にコピーできる。図は種名、期間、地点時刻、閾値とその由来・評価状態、凡例を含むPNG／SVG。HTMLの図・音声リンクから種一覧へ戻れる。音声プレイヤーは再生時に一つだけ作る。画像の縦横を先に確保して、遅延読み込みによるページ内リンクのずれを防ぐ。

要約、種一覧、種ごとの図、検証の結果と不確かさ、クイズ練習の補足、参照音のスペクトログラムと再生、根拠音、元データの順に掲載する。未解析の録音が残る場合は要約で明示する。短期間の図は2列、94日以上は1列。種数が増えても文字や図を縮めない。

## 集計・検証の接続

- 地点・現地期間・録音ID集合を保存時点で固定する。同じ地点に複数の取り込みがあっても、期間外の録音は本文・集計・音・スコアCSVに含めない。日付をまたぐ音は期間内の録音秒数のみ数え、検出15秒／検索5秒は全体が期間内に入る完全区間を使う。
- 検出では種・モデル、検索では種・参照音群・モデル別の検証を参照する。調整した基準は別標本の評価中から全対象区間へ適用する。調整と目標達成を混同しない。
- 検索の調整は類似度の3帯から無作為抽出し、帯の母数／抽出数で重み付けする。標本上のprecision 90%以上、正例3件以上を満たす中でrecallを優先する。条件を満たす値がなければ未設定。旧中央値中点を通常の図や新しい報告へ自動適用しない。
- 独立評価では調整用と、評価開始までに検索で判定済みだった同じ区間を除外する。抽出母数・確率・乱数・回答を保存し、既存の有限母集団の区間推定を再利用する。未解決回答を消さず、precision・recallの95%範囲を出す。検索で閾値が未設定なら基準以上の件数・割合は未集計とする。
- 2026-09-13更新：10音ごとの途中評価も出力できる。HTML・図・CSVで途中評価と完了を区別し、評価に使用した音数と更新点間の未使用回答を混同しない。新しい評価の95%範囲は、同じ検証内の全予定更新点・全層を同時に考慮する。回答の訂正で現在の結果は更新し、以前のHTML・音・JSON・ZIPは変更しない。詳細は [検証仕様](validation-design.md)。
- 図・表・CSVに同じ `score >= threshold` を適用する。検出図は15秒区間率、検索図は時間帯内の最大類似度。類似度を頻度や正答確率にしない。個々のAI検出の確認・訂正は追加しない。
- 対象種が正解の問題について、直近の練習の正解／回答数、保留数、日時、セッション・問題集合のハッシュを補足へ掲載する。検証と検索の各回答にも、その時点の練習成績を保存する。後日更新しない。未見の能力テストや現地同定精度とは扱わず、検出数や品質へ点数を掛けない。

## 一式の構造

| ファイル | 内容 |
|---|---|
| `index.html` | 本文、表、図へのリンク、参照音と保存した根拠音の再生。外部サービスへの読み込みなし |
| `report.txt` / `report-content.json` | 転記用の本文・表と生成内容 |
| `figures/*.png` / `*.svg` | 種別の図。PNG 1,920×2,240px、SVGはベクトル |
| `species.csv` / `hourly.csv` | 種・方法別の区間数、分母、割合、日数、日時セルの集計 |
| `scores/Fxxx.csv` | 閾値未満も含む全対象区間のスコア。閾値で集計を再現できる |
| `quality.csv` / `validation/*.json` | 適用した検証、precision・recallと不確かさ、標本・回答・回答時点の練習 |
| `quiz-results.json` | 関連する回答済み練習の保存記録 |
| `evidence.csv` / `audio/` | AIの例、検証回答、検索正例と再生音声の対応 |
| `references.json` / `references/` | 全参照区間の図・選択音声、重複を避けた原音、出典・変換・ハッシュ |
| `manifest.json` / `results/` / `recordings.json` | 対象範囲、設定・元スコアの版、ファイルのSHA256と大きさ |

再生用の切り出しは元のサンプリング周波数を保ったモノラルfloat WAVとし、不要な再サンプリングをしない。モデル入力の変換条件は参照音の検索スナップショットに別途保持する。

AIの例は各結果のスコア上位5区間（BirdNET 3秒／Perch 5秒）。検証で回答した音は実際の15秒／5秒を保存し、低スコアの正例も残す。検索の保存済み正例は20件等で切り捨てない。元参照音が変更・削除されていたら、その音は非同梱理由を記録する。

一時フォルダへ生成し、内容と元録音・更新状態を確認後にフォルダとZIPを公開する。失敗時には途中の出力とDB履歴を残さない。過去の一式は新しい音声・判定・クイズで書き換えない。新しい描画依存はPillowのみ。日本語図用のBIZ UDGothicとOFL、Roseusの利用条件を同梱する。Office・PDF変換ソフトは不要。

# 報告機能の実装（2026-09-08）

本書は9月8日の初期実装・動作確認の記録。2026-09-11に再確認した完成仕様は [報告案](report-usability-proposal-2026-09.md) を参照する。
検出・検索とも人の検証データに基づく種別閾値を全結果へ適用し、個別のAI検出の確認・訂正は行わない。
下記の探索用検索閾値は当時の実装上の制約であり、完成仕様ではない。検出側の後続の品質評価実装は [検証設計](validation-design.md) 末尾の記録を参照する。

[了承済みの出力案](reporting-design.md)に沿った初期実装。
「報告」画面から検出・検索を選び、地点の現地日付で期間を指定して作成する。
検出はモデルを選び、種一覧の行からその種の図と根拠候補へ進む。
検索は保存検索を選ぶ。閾値なしの最大類似度表示にも対応する。

## 集計の意味

- **検出**: 録音開始を基準とする、重複しない完全な15秒窓を使用。
  BirdNET の3秒×5区間、Perch の5秒×3区間の最大スコアを閾値と比較する。
  15秒に満たない末尾、スコアが揃わない窓、地域条件が不明な解析を陰性扱いしない。
  Perch は全クラス softmax 後に地域を絞る。表示上位100件とは独立に、保存した全スコアを読む。
  種ごとの候補窓数／有効窓数と候補日数／有効日数を出す。
- **検索**: 保存検索に含まれる全区間を使う。表示件数や無作為抽出数で図の母集団を変えない。
  5秒ごとの最大参照類似度から、各セルの最大・平均、任意の閾値以上の窓数・率を求める。
  元の検索と同様、末尾が5秒未満でも一区間とする（モデル入力はゼロ埋め）。
  有効秒数には実際の音源部分だけを数える。参照音と重なる自己区間は検索時の除外を引き継ぐ。
- 日付×1時間へ窓の開始時刻で割り当てる。窓が時刻境界を跨いでも重複計数しない。
  録音努力は実経過秒数を現地時刻へ割り当てるため、夏時間の重複時刻も二重計数しない。
  録音なし、未解析、種を評価できない状態、一部解析、解析済みの低値を区別する。

## 図・根拠・探索用閾値

角度は現地の時刻、内側から外側が日付。1〜366日、最大8,784セルに対応する。
Echoroo full の SVG による扇形配置を流用し、新しい描画ライブラリは追加していない。
拡大・セル選択・キーボード操作に対応。検出は0〜1の候補区間率、検索は閾値〜1の最大類似度を
固定の値域で色付けし、閾値未満は中立色、対象種と判定した区間があるセルには別の印を付ける。
年表示では細い境界線による縞模様を避ける。図には日付の目盛り、条件、凡例、品質の注意書きを残す。

根拠一覧は選択セル又は全期間について最大100件を表示し、確認済み正例を優先する。
CSV は全根拠を含む。検出の根拠は15秒窓内で最高スコアとなった元の3秒／5秒区間。
検索は閾値以上に加えて判定済みの区間を保持し、低スコアの正例も消さない。

検索の判定分布は cosine の −1〜1 を20帯に分けて表示する。
対象種・対象外がそれぞれ3件以上あり、正例の中央値が負例より高い場合だけ、
両中央値の中点を色境界の候補にする。これは実装上の簡単な探索用目安であり、
最適閾値、推定 precision、独立した評価済み検出器とは扱わない。
不明・未回答は負例にしない。利用者が候補を採用又は手動調整すると別の報告を作る。

## 保存と書き出し

作成時のモデルハッシュ、解析ID、設定、種名、日付、閾値、検索条件と人の判定の時点を
SQLite に保存する。再解析・後日の判定で過去の報告を上書きしない。
過去の検出一覧の種を開く場合も、元の報告が使った解析を参照する。

選択した保存先へ一意のファイル名の ZIP を作成する。

| ファイル | 内容 |
|---|---|
| `spiral.svg` / `spiral.png` | 種を選択した図。UIの言語で書き出す。PNGは幅2,400px |
| `species.csv` | 種ID、日英一般名・学名、モデル／検索条件、候補数・率・日数 |
| `hourly.csv` | 日付・時刻ごとの録音秒数、有効窓数、候補数・率、最大・平均類似度、状態 |
| `evidence.csv` | 全根拠の元録音・区間・判定・解析IDと、選択した書出音声との対応 |
| `quality.csv` | 種ごとの品質未評価状態。未算出の precision / recall / 検証IDは空欄 |
| `report.json` / `recordings.json` | 条件・集計・解析設定のスナップショットと元録音の情報 |
| `audio/` | 選択した最大200区間。32kHzモノラルのfloat WAVと区間の対応情報 |

CSV はロケール非依存の英語列名と UTF-8 BOM を使う。ユーザー入力名の表計算式解釈を抑止する。
元録音は書き換えず、短い根拠音だけを読み出す。書き出し中に失敗した新規ZIPは除去する。
一般名の変更後も既存の報告は保存時の名前を保つ。

## 2026-09-16：時間範囲を付けた鳴き声の出力

AIや検索で見つからなくても、人が名前と範囲を付けた種は掲載できる。「録音を聴いて範囲を選んだ鳴き声」として、確認した15秒（検索の種別検証は5秒）の図、陰影で隠さない範囲の印、正確に切り出した音、日時・回答番号を対応させる。種不明の範囲も別途残す。未記載や範囲の外を陰性にせず、区間数はその人が同定した記録の数として表示する。これだけから全録音の頻度・季節性の図を作らない。

`annotations/ranges.csv` と `ranges.json` に元録音ID、元録音内の開始・終了秒、聴取した区間、回答版、音声への相対パスを保存する。JSONは種名と回答時点の練習も含む。`annotations/<session>.json` は抽出計画・固定した録音・層・種名一覧と追加名・回答履歴を保持する。元スコアや現在の表示へ依存しない保存時点の一式とする。

共通注釈から始めた検出品質は、閾値調整に使う録音と評価に使う録音を分離する。その評価側で得た数字を図の全対象へ無条件に一般化しないよう、本文にも対象範囲を明示する。範囲の訂正で古くなった品質を現在の結果へ適用しない。既に保存したHTML／ZIPは後日の訂正で変更しない。
