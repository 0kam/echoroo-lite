# 種名と外観（2026-09-08）

ユーザーの希望を受け、初期版は **BirdNET の名前＋ユーザー追加**とし、
**選択言語の一般名＋学名**を表示する。full の多段の分類・一般名解決は移植しない。
外観は Echoroo full の配色と実際のロゴを流用する。

## 種名の扱い

- 一般名は同じ言語の **ユーザー入力 > BirdNET 同梱名**。選択言語の名前がなければ英語、
  英語もなければ「一般名未登録」と学名を表示する。現在は日英を同梱する。
  クイズ素材のキジ `Phasianus versicolor` だけは `species-extra.json` に日英名を補足し、
  BirdNET名より低い優先順位で使用する。コウライキジとは別の種IDを維持する。
- BirdNET 2.4 の生物ラベル6,512件に日英名を付けた。Perch V2 の生物ラベルも含む
  14,847件を収録するが、Perch 独自の種の一般名を推測して補わない。
  学名が完全一致する場合だけ両モデルで同じ名前を使用する。異名や分類の分割・統合は
  自動解決しない。一般名の追加だけでモデルの検出対象が増えるわけではない。
- SQLite の `species` は初回作成時の UUIDv4・学名・言語ごとの上書き名を保持する。
  名前を編集しても ID は変わらない。ID はインストール間で共通ではない。
  学名の変更・種の統合 UI は初期版に設けない。
- 元の分類ラベル・モデル版・スコアは解析結果に保持する。API の読み出し時に表示名を
  添えるため、名前の変更は保存済み候補にも再解析なしで反映される。
  人声・環境音など生物以外のラベルは「音のカテゴリ」として元ラベルを表示する。
- 「種名の管理」で一般名／学名を検索し、種の追加と日英名の上書きができる。
  空欄保存でその言語の上書きを取り消し、同梱名へ戻る。追加・編集は手元の DB に保存する。
- 検索順位は **完全一致 > 前方一致 > 部分一致**。同順位では一致した名前が短い順、
  次に学名順。全候補の順位を決めてから50件に絞る。「ウグイス」は「ウグイストゲハシムシクイ」より先に出る。

`scripts/build_species_names.py` が既存の取得済みモデルラベルから
`apps/sidecar/data/species.json` を生成する。入力ファイル名・モデル版・SHA-256 を
JSON に記録した。UTF-8 で読み書きし、PyInstaller に同梱するため、表示にネット接続は不要。
名前を収録するデータと利用者の上書きは分離し、再生成で上書きを消さない。

## Perch の表示スコアと地域フィルタ

2026-09-08 の追加修正として、アプリでは両モデルに地域フィルタを常時適用する。
BirdNET は解析時、Perch は保存済みの全スコアから表示候補を選ぶ際に適用する。
Perch だけにあった切り替え UI は、ユーザーの指摘を受けて削除し、両モデル共通の説明に統一した。
これは Perch 固有の分布モデルではなく、同じ解析地点の BirdNET 地域候補との学名の完全一致。
現行の地域条件は BirdNET と同じ通年・閾値0.03で、テスト地点では Perch 298種が一致した。
地域リストにない種や異名で一致しない種は表示対象外となる。Perch の元の全クラス出力と
埋め込みは保持し、診断用 API の全クラス取得も維持する。通常画面には切り替えを設けない。

[Google の公式説明](https://www.kaggle.com/models/google/bird-vocalization-classifier)では、
Perch V2 は softmax head で学習し、推論時は softmax 前の logit を出力する。
Lite は **全14,795クラスに softmax を適用して0〜1へ変換し、その後で地域候補を選ぶ**。
地域内だけで再正規化しないため、地域フィルタによってスコアが水増しされない。
スコアは未較正で、同定の正答確率や BirdNET と同じ検出品質を意味しない。
複数種が同時に鳴く場合もクラス間で競合するため、報告の閾値・品質評価はモデルごとに行う。

全 logit・ラベル・埋め込みは保存したまま、読み出し時に全スコアから候補を作る。
先に全種上位5件へ絞る処理は廃止し、地域内の種が世界全体で6位以下でも表示候補へ復元する。
新規解析では地域リストと条件を Perch にも保存する。旧解析は同じ録音・同じジョブの BirdNET
保存条件を使い、別ジョブの地域条件を流用しない。条件がなければ「地域リストなし」と明示し、
絞り込み中は候補を返さない。元の保存データを変更せず、再解析なしで旧結果にも適用する。

## Echoroo full から流用したもの

参照元は `0kam/echoroo` のコミット `954457acfb24e22adae9aecf92796a84530baeae`。
Linux 側の実ファイルを読み、次を Lite に取り込んだ。

| full のファイル | Lite での用途 |
|---|---|
| `apps/web/static/echoroo.png` | 同じ PNG をヘッダーに表示（高さ24px） |
| `apps/web/static/favicon.svg` | 同じ SVG を favicon に使用。デスクトップアイコンは描画パスと色を保持して余白を正方形に調整し、Tauri CLI で各形式を生成 |
| `apps/web/src/app.css` | Rosé Pine Dawn / Main のカラー変数から使用分を `apps/web/src/lib/theme.css` に移植 |
| `apps/web/src/routes/(app)/+layout.svelte` 等 | 48px ヘッダー、224px サイドバー、カードとローズ系アクセントを参考に Lite の画面へ適用 |

ライトは暖色の背景、ダークは紫系の背景。オレンジ `#FF5A00` は既存ロゴの色を維持する。
テーマは画面上部で切り替え、端末内に保存する。CSS と既存 Svelte のみで実装し、
スタイル用ライブラリやオンラインの名前解決依存を追加していない。

## 確認

- API テストで日英名、上書き優先、空欄復元、追加種、再起動後の ID 保持を確認。
  BirdNET / Perch の共通名、一般名のない Perch 種、非生物ラベル、元の解析ラベル保持も確認した。
- Mac のネイティブ画面で日英切り替え、両モデルの一般名＋学名、名前の検索・保存、
  ライト／ダーク表示を確認。既存の朝6時の録音と解析履歴を使用し、再解析は不要だった。
- Svelte 検査・静的ビルドと Mac 開発用 `.app` の作成に成功。
  Mac の凍結サイドカーでも日本語の同梱名を API から取得できた。
- クイズの自分の回答・復習欄と報告履歴にも学名を補った。
  更新した Mac 配布版で日英の一般名切り替えと学名の保持を確認。
  表示確認用の学習履歴 #2 は、ハクセキレイの問題にハシブトガラスを選んだ操作試験であり、
  利用者の同定能力の測定結果ではない。既存の学習・報告履歴は保持されている。

Windows 実機の表示・動作確認は引き続き展示版の受け入れ項目とする。
