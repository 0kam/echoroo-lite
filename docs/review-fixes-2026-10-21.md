## 合意

- 既存要件の範囲の A1〜A19（文言の整理を含む）を直す。
- B1（数え方の確認で基準が決まったときだけ「聞こえる」を［いるか］の根拠にする）は**取り下げ**。
  基準を決められないのはAIの誤りが多いときにも起こり、人の「聞こえる」はそれでも根拠になりうる。
  聞き間違いへの対策は、再生してから答える（A4）、お手本の聞き比べ、注意の表示で行う。
- B2：お手本がない種では、［いるか］で押す前に一言注意する。**「場違いな種」の注意は保留**（下記）。

- B4：種のページの「検出した音を聞く」をなくす。［いるか］の一覧が音を聞く場所になる。
- B5：AIの一覧にある種では「お手本の声で検索」を常設しない。［いるか］で確認できなかったときだけ出す。
  種のモデルの案内も、確かめたAIがすべて数え方を決められなかったときだけ出す。

## 文言（利用者に見える言葉）

| 今 | 直す |
|---|---|
| 基準 | AIの数え方（スコアがいくつ以上を「声あり」と数えるか） |
| 基準が決まった（スコア0.264以上） | 数え方が決まった（AIのスコア0.26以上を数える） |
| 基準を決められなかった | 数え方を決められなかった（AIの誤りが多いか、答えがばらついた） |
| 基準以上だった区間の割合 | AIが声ありと数えた時間の割合 |
| 90%の確からしさで | ほぼ確実な範囲（90%） |
| 補正倍率 | 数え方の補正（×n） |
| AUPRC、スコア順の群 | 画面には出さない（書き出しの付録・CSVにだけ残す） |
| 作成したモデル #1／種のモデル | この種用に作ったAI（9/22作成） |
| 似ている度合い 0.29 | 似ている度合い 0.29（1に近いほど似ている） |
| 聞いた音が少なく、見落としの程度は分かりません | 珍しい種のため、見落としの程度は分かりません |
| Xeno-Canto の API キー | Xeno-Canto（鳥の声の共有サイト）の利用キー |

戻る操作は「〇〇に戻る」の形にそろえる。「聴く」は「聞く」。英語は同じ意味で平易に（単数・複数を正しく）。
