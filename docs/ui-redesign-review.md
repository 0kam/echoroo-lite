## 修正した不具合

- 内部リンクと `goto` にハッシュがなく遷移が失敗するため、SvelteKit標準の `resolve` を使用。
- API件数カウンタの読み書きが呼び出し元のeffectを再実行し、録音一覧が無限に再取得された。
  カウンタ更新を `untrack` で囲み、進行表示を保ったまま依存追跡から外した。
- 接続前の子画面API呼び出しを防止し、ルート変更時に画面状態を再初期化。
- 録音から検索への引き継ぎでは、ハッシュ内の `recording` パラメータを読む。
- 共通Buttonの既定を `type="button"` にし、意図しないフォーム送信を防止。
- メタデータ待機中の停止・画面離脱で再生を取り消し、古い待機処理の後からの再生を防止。
- カタログの定期取得だけで候補行の選択がリセットされないよう修正。
- 取り込みプレビューの日時を地点のタイムゾーンで表示し、報告履歴の日付に混入した `$` を除去。
- ナビゲーションの装飾番号・記号を読み上げ対象から外し、Windows検査の検索導線を更新。
- 検索画面の初期取得エラーを表示する。
- 5秒未満の録音では初期選択を録音の長さに収める（3秒の実録音区間で確認）。
- ダーク表示の類似度分布でバーと数値のコントラストを修正。
- Mac配布版の初期URL `tauri://localhost` でハッシュルーターが再読み込みを繰り返した。
  Tauriのwindow.urlを `/` に明示して `tauri://localhost/` から起動し、通常の配布ビルドで確認。
  診断時だけdevtools機能を有効にしたが、配布用には含めていない。
