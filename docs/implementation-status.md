## 2026-11-09：Tauri で音が鳴らなくなる不具合

Tauri で音の地図を使っていると「録音を読み込めません。」と出て、どの音も鳴らなくなった（ユーザーの報告）。

- 原因：音の部品（`AudioRegion.svelte`）が一覧の 1 行ごとに `<audio preload="metadata">` を持ち、表示しただけで WebKit の再生器を作って音声を読みに行っていた。地図の点を押すたびに一覧の 20 件が作り直される。macOS の記録では、同じ WebKit の GPU プロセスで再生器が約 400 個作られた後、新しい再生器は読み込みの要求すら出さずに 10 秒で打ち切られていた（AVFoundation の -1001）。sidecar は正常（同じ要求に 206 で応答）。開発用のブラウザ（Chromium）では起きない。
- 修正：`preload="none"` にして、再生を押したときに読み込みを始める。部品が消えるときは `src` を外して再生器をすぐ手放す。
- 確認：Svelte 検査 0 errors / 0 warnings。開発ブラウザで、表示しただけでは 21 個の音声がどれも読み込まれず、点を押すとカードの音が自動で鳴り、一覧の音の再生ボタンも鳴る（カードの音は止まる）。修正後の Tauri で音が鳴ることをユーザーが確認（同日）。
- 同じ部品はリリース版の検証や種のページでも使っているので、リリース版でも起きうる。

## 動くところ

- Tauri が Python サービスを起動し、空きポートと一時トークンを受け取る。
  サービスは loopback のみ。登録済み音源を ID 経由で再生する。
- 地点 → 録音群を作成し、フォルダと子フォルダのモノラル WAV / FLAC を参照登録する。
  現在は末尾 `YYYYMMDD_HHMMSS` の日時に対応。取り込み前に件数・スキップ理由を表示する。
  大きな録音群は100件ずつ表示し、地点ローカルの録音日で絞り込める。
- 地点の IANA タイムゾーンで日時を解釈し、元日時・タイムゾーン・UTC を保存する。
  夏時間の重複／存在しない時刻をエラーにし、黙って補正しない。
- 重複パスをスキップ。登録後に元音源のサイズ・更新日時が変わると再生・解析を止める。
- 録音単体又は録音群を BirdNET 2.4 / LiteRT と Perch V2 / ONNX で解析する。
  進捗・完了／失敗／停止／再起動による中断状態を SQLite に保存する。
- BirdNET は既存 PoC と同じ通年の地域フィルタを使用し、対象ラベル集合の全スコアを保存。
  Perch は全 14,795 ラベルの logits と全 5 秒区間の 1,536 次元埋め込みを保存する。
  NPZ は pickle を使わず読み出せる。モデル・ラベルのハッシュと設定を結果へ記録する。
- 表示候補は区間ごとの上位5件、各モデル最大100件。BirdNET 表示下限は0.1。
  候補の区間ボタンから再生し、区間末尾で停止する。解析履歴番号と各モデルのスコア尺度を表示する。
- Perch は全クラス softmax 後の0〜1を表示し、BirdNET と同じ地域リストに限定する。
  通常画面は両モデルとも地域フィルタを常時適用し、共通の説明だけを表示する。
  絞り込み前の全 logit から候補を取り直すため、
  旧解析にも再解析なしで適用できる。地域条件は同じジョブの記録を使用する。
- スペクトログラムを5〜60秒ずつ表示し、ドラッグまたは秒数入力で区間を選択・再生する。
  登録済み録音／手元の WAV・FLAC・MP3 を参照音にして、録音群内の類似音上位30件を検索・試聴できる。
  分類の地域フィルタは検索に適用しない。検索した録音数／全録音数とモデル入力区間を表示する。
  種ごとの複数参照区間と全対象区間の類似度を保存検索として保持する。
  録音開始日の現地日付で検索期間を指定し、抽出前に全対象区間の類似度分布を表示する。
  条件は保存検索・報告・PNG/SVG・CSVへ保持する。
  類似度帯の無作為抽出、試聴、対象種／対象外／不明の判定保存に対応。
  Xeno-Canto のキー設定・種／国／品質検索・選択音源の帰属付き取得も実装し、Mac配布版で実接続を確認した。
  詳細・制約は [search-implementation.md](search-implementation.md)。
- 日本語・英語を切り替えて保存する。日時の表示形式だけを変え、録音の瞬間は変えない。
- 報告画面で検出／検索を分け、種一覧・根拠候補の試聴・日付×時刻の spiral plot を表示する。
  両モデルの検出は完全な15秒窓、検索は保存検索の全5秒区間を使う。
  1〜366日の拡大表示、セルから根拠の選択、SVG／PNG／CSV／選択音声のZIP書き出しに対応。
  解析版・閾値・判定時点を固定して履歴を保存し、品質未評価を明示する。
  集計の定義と制約は [report-implementation.md](report-implementation.md)。
- 種名を選択言語の一般名＋学名で表示する。BirdNET の日英名とユーザーの追加・上書きを使い、
  Perch も学名が完全一致する種には同じ名前を表示する。名前変更で内部 UUID・元の解析結果は変わらない。
  名前の検索は完全一致・前方一致・部分一致の順に並べてから上位50件を返す。
- `koe-e-lab/sample_data` の26種・音声と写真を同梱し、問題セットの保存、学習クイズ、
  正誤／不明と種別の集計、途中再開、再試聴を実装した。
  手元・録音群・XCの音源からUIで区間を選び、独立した問題用音声として保存する。
  練習成績と実際の同定能力・検出品質を区別する。詳細は [quiz-implementation.md](quiz-implementation.md)。
- Echoroo full の配色・PNG ロゴ・SVG favicon を流用し、デスクトップアイコンも作り直した。
  ライト／ダークを切り替えて保存できる。詳細は [species-and-branding.md](species-and-branding.md)。
- PyInstaller のビルド／疎通確認スクリプトと Windows のビルド workflow を追加した。
  ビルド前にモデル取得・検証スクリプトを実行し、固定した BirdNET／Perch モデルを配布版へ同梱する。
  配布版はオフラインで解析でき、別途モデルを準備する必要はない（アプリ容量は約 480 MB 増える）。
- BirdNETの公開セッションAPIで処理用プロセスをジョブ内で再利用する。
  録音ごとの保存・キャンセル境界、1ワーカーの制限と元スコアは維持する。
