# 年間プロトコルの負荷試験（2026-09-08〜09、JST）

M4 Pro / 24 GiB の凍結サービスで、1地点年相当の17,520本・292時間を
**4時間8分25秒**で処理し、検索・報告CSV・選択音声の出力まで正常終了した。
この端末・条件では12時間以内の計算条件を満たす。Windows実測は未実施。

## 入力と測定範囲

- 指定された `whombat_data/test` の24本・12時間を、720個の1分区間に分割。
  これを繰り返し、2025年の30分おき・17,520本として配置した。
  **実音声を反復する性能試験であり、実際の年間の生態データではない。**
- 入力はハードリンクで容量を節約するが、各ファイルでデコード・両モデル推論・保存を実行する。
  元音源を変更せず、専用カタログ `.local-data/protocol-year-17520/data` を使用した。
- macOS 26.5.2 / ARM64、M4 Pro、24 GiB、論理CPU12。
  BirdNETは1ワーカーをジョブ内で再利用、PerchはCPU8スレッド。
  計測中に配布アプリのビルドや操作確認も行っており、他のアプリを停止した専用環境ではない。
- 初回モデル取得、入力用ハードリンク等の準備6.11秒、GUI描画と手操作はサービス時間の外。
  準備時間を加えても12時間以内。GUIの年間図は完走後に別途確認した。

## 実測

| 工程 | 時間 |
|---|---:|
| サービス起動 | 2.80秒 |
| 取り込みプレビュー・登録・一覧取得 | 4.83秒 |
| 両モデル解析・埋め込み・DB保存 | 14,402.24秒（約4時間） |
| 全区間の試行検索 | 78.33秒 |
| 2種・各2参照区間の保存検索 | 168.27秒 |
| 30区間の抽出・不明判定の保存 | 0.45秒 |
| BirdNETの年間報告 | 135.61秒 |
| Perchの年間報告 | 107.71秒 |
| 保存検索の年間報告 | 1.45秒 |
| 3報告のCSV ZIP・選択音声出力 | 1.26秒 |
| 全サービス工程（検査用API呼び出しを含む） | **14,905.24秒** |

- 両モデルとも17,520解析、Perch 210,240ベクトル、正常終了コード0。
  保存検索はウグイス・キジそれぞれ210,240区間。参照音は同梱素材の0〜3秒・5〜8秒。
- サンプル取得したプロセス群の最大RSSは **1.56 GB（1.45 GiB）**。
  1秒間隔の合算値なので共有ページの重複や短いピークの見落としがあり、端末全体のメモリではない。
- アプリ保存データは **19.05 GB（17.74 GiB）**。元音声・入力用ファイル・モデル・書き出し先は別。
- 検出報告の共通15秒窓は各70,080、検索報告の5秒窓は210,240。
  各時間集計は8,760行、録音時間の合計は1,051,200秒。
  全品質CSVのprecision / recallは空欄で、`not_evaluated`を維持する。

## 配布アプリでの確認

完走後、同じデータをMac配布 `.app` で開き、17,520本の一覧、両モデルと検索の
保存済み年間報告、365日・8,760セルの図、拡大表示を確認した。
検索図でTab・矢印キー・Enterから2025-01-01 1時のセルを選び、録音2分・有効24区間、
最大類似度0.254・平均0.240・候補0件の表示が時間集計CSVと一致した。

3報告とも保存ダイアログからPNG（2400×2605）・SVGを含むZIPを出力し、図を目視確認。
SVGは8,760セルを保持する。再起動前後の `report.json` と集計CSVは一致し、
検索の根拠CSVだけは選択音声の有無に対応する `audio_file` 列が1行異なる。
これは計測側が「不明」の5秒音声を含め、GUI側が図の確認のため音声を選ばなかった差である。

## 再現と証拠

```sh
.venv/bin/python scripts/benchmark_protocol.py --source /Users/okamoto/Music/whombat_data/test --output .local-data/protocol-year-17520 --binary apps/desktop/binaries/echoroo-sidecar-aarch64-apple-darwin --count 17520
```

再実行時は新しい出力先を使う。入力対応表は `inputs.json`、機械可読結果は `result.json`、
図とCSVは同ディレクトリの `exports/` にある。抽出した図は
`annual-birdnet.png`、`annual-perch.png`、`annual-search.png` と対応するSVG。
使用した凍結バイナリのSHA-256は
`3027bff04add097dad4d4b9468314ff57d5c3cd3e92a3a380816a9c04beb1da9`。
モデルのハッシュも `result.json` に記録している。

単発の性能確認であり、検出品質・実際の季節性・Windowsの速度は示さない。
Windows配布版とXeno-Canto実接続は本試験の対象外。
別途の確認状況は [implementation-status.md](implementation-status.md) を参照。
