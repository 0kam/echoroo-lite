## 2. 検出と検索で目的・出力を分ける

| | 検出 | 検索 |

| 基本結果 | BirdNET / Perch の版付き分類結果 | 種別の参照音群に対する類似度と、検索標本への人の判定 |

**通常の検出一覧を逐一確認・訂正する汎用機能は、初期版から省く。**
AI の出力は保持し、検出品質は検証セット上で測る。個別に人が確認した結果だけを集計・掲載する制限は設けない。種の付け替えや網羅的なアノテーション
編集を必須の操作にはしない。検証データ作成と検索標本への判定に人の作業を集約する。

一方、検索の「対象種／対象外／判断できない」の保存はユーザー指定の機能として残す。
同じ区間が複数種の検索に出ても、判定は対象種ごとに持つ。未回答の種を陰性としない。
検証と検索は再生・スペクトログラム・判定 UI を共用し、抽出目的・条件は別に保存する。

### 検証の実装と展示時の定量的な信頼度の関係

検証画面での操作を展示時に必須にしなくても、事前に作った検証結果を表示することはできる。
対応する現地検証結果がある種には precision / recall、標本数、区間推定、適用範囲を添える。
検証がない種は原検出の図を「品質未評価」と表示し、モデルスコアを正答確率にはしない。
展示用の品質数値を出すには、対象音源・種で参照判定を先に作る必要がある。
クイズ成績だけで現地の検出品質を数値化しない。

## 3. 検出の出力案

- **種一覧**: 和名・学名、モデル、対象地点・期間、検出された区間数／有効区間数、
  検出日数／有効録音日数、検証状態と品質指標、根拠候補音源へのリンク。
  根拠候補が未確認なら「AI 候補」と表示する。正の検証ラベルがある音は確認済み根拠に使える。
  種一覧の行数を確認済みの生物種数とは呼ばない。
- **集計単位**: 両モデルの比較用に共通の 15 秒窓を試す提案。各モデルの窓を重複計数せず、
  共通窓での有無判定を定義して閾値・検証条件と揃える。1 分録音の有無とは別の指標。
- **spiral plot**: full の配置を引き継ぎ、角度＝設置場所の時刻、内→外＝日付とする。
  初期のセルは日付×1時間。色はそのセルの検出区間率。モデルは別の図にし、同じ値域で比較。
  セルから対象音源・区間を再生できるようにする。年間表示は表示密度と拡大操作を試作確認する。
- **補正値**: 根拠のある期間・条件で補正区間率を表示する。全期間の品質値を
  各日・各時刻へ一律適用しない。細分したセルの根拠が不足する場合は原検出図を維持し、
  粗い集計の推定値と不確かさを別に示す。
- **書き出し**: 図は PNG と SVG を提案。種一覧・時間集計・品質指標・根拠一覧を CSV で出す。
  根拠音声は選択した短い区間を書き出し、元録音 ID・開始終了時刻と対応付ける案。

## 4. 検索の操作と複数音源の扱い

ユーザー指定の流れ:

1. Xeno-Canto を種名・国・クオリティで検索する。
2. 一覧から素材を選び、スペクトログラム上で時間範囲を指定して試聴する。
3. 複数種・各種複数音源を検索条件へ追加する。オリジナル音源も素材に使う案。
4. 対象地点・録音群・期間を選び、全対象録音の埋め込みとの類似度を計算する。
5. 種ごとに類似度分布を表示し、指定した範囲から指定数を無作為に抽出する。
6. 対象種かを判別し、正例を根拠音源として保存する。
7. 判定標本を検証データとして種・参照音別の類似度閾値を調整し、全検索対象に適用してspiral plot・集計CSVを出力する。閾値の調整と別標本での品質評価を区別する。

複数音源の計算案: 対象種 s の参照音群 Q_s に対して、各 5 秒区間 w のスコアを
`S(s,w) = max(q in Q_s) cosine(embedding(w), embedding(q))` とする。
同じ種の異なる鳴き方を平均で薄めず、どの参照音が最大一致したかを保持する。
異なる種の参照音はまとめず、種別に結果・閾値・図を持つ。
参照範囲がモデル窓より長い場合の分割、短い場合の処理は実装前に PoC で確認し、
元の選択範囲とモデルへ実際に入力した範囲を記録する。

同一の区間に複数参照音が一致しても、対象種内では一区間として扱う。
参照音の追加で最大値の分布が変わるため、参照音群の版を固定して閾値・図と結び付ける。
cosine の負値を含む生スコアは保持する。類似度は同定の正答確率ではない。

## 5. 検索の spiral plot と閾値

**初期表示は各セル内の最大類似度を推奨する。** 短い鳴き声が一度だけ入った場合にも
見つけやすい。例えば 12 区間のうち一つが 0.9、残りが 0.1 なら、平均は約 0.167 に
薄まるが最大は 0.9。平均類似度は CSV に残し、初期 UI は最大値中心とする案。

- セル集計は、抽出して人が聞いた標本だけでなく、対象範囲の全解析区間から計算する。
  表示件数やサンプリング回数を変えても、同じ対象範囲の図は変わらない。
- 色は `S < th` を薄い中立色、`S >= th` を閾値から上限へ向かう連続色とする。
  境界と値域を凡例に明示し、CSV の数値は変更しない。閾値が未設定でも図は参照表示できる。
  初期上限は cosine の上限 1 とする案。比較中の図で自動的に値域を変えない。
- 確認済み正例は別の印で示す。人が正例とした低スコア音が閾値以下でも根拠は消さない。
- セルごとに全区間数・有効録音時間を表示する。最大値は録音量が多いほど高くなる
  機会が増えるため、異なる録音努力での頻度比較にはそのまま使わない。
- 「どれくらい出るか」の参考値として、同じ 5 秒窓の **閾値超過区間数／有効区間数**と
  その日数を併記する案。最大類似度・平均類似度のどちらも個体数ではない。
  閾値超過率も、現地検証がなければ誤検出と見逃しが残る「類似候補の頻度」。
- 声を正しく確認できた場合、その録音日時に対象種の声を確認した根拠になる。
  全ての標本が陰性でも「今回の検索では未確認」とし、不在の確定へ置き換えない。

2026-09-11の確定方針：種・参照音群ごとの正例／負例／保留を使って類似度閾値を調整し、全対象区間の表示と集計に適用する。個別に人が確認したヒットだけを報告へ採用する手順は追加しない。
閾値の自動選択・独立評価の具体的な標本設計は [検証設計](validation-design.md) に記録する。適合率の既定目標90%、達成の評価、誤検出・見逃しの補正は別の事項として扱う。
precisionには閾値以上、recallにはその下も含む範囲を代表する標本が必要で、類似度帯の母数・抽出数・抽出方法・乱数seedを保存する。探索途中に偏って追加した回答を無条件に評価標本へ混ぜない。
標本が限られる場合も判定を調整に活用するが、全体への品質評価が成立していないことを明示する。標本不足や正例・負例の不足で閾値を決められない場合は未調整とし、品質数値を作らない。

現行コードの正負中央値の中点は探索用の簡易実装である。これを完成仕様として維持するのではなく、上記の検証データに基づく調整・評価・全結果への適用へ接続する。まだ実装済みとはしない。
