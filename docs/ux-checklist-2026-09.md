## 全画面で確認すること

- [ ] 見出しだけで、対象の地点・種と今の作業を説明できる。
- [ ] 操作説明を読まなくても、最初に押すボタンがわかる。
- [ ] 一画面に違う目的のフォーム・一覧・管理操作が混在していない。
- [ ] 内部用語の知識を要求しない。文言を大学1年生程度の言葉で言い換えられる。
- [ ] 通常文字が読みやすく、主要操作は44px以上。1280×800で主要操作が押せる。
- [ ] キーボードで操作でき、選択・フォーカスが見える。色だけで状態を伝えない。
- [ ] 大きな戻る操作があり、戻った後も入力・回答・対象・位置が保たれる。
- [ ] 読み込み中・処理中がすぐわかる。完了すると成果と次の操作が見える。
- [ ] エラーはその場で原因と次の行動がわかる。再試行で二重登録しない。
- [ ] 日本語・英語の両方で成立。言語を変えても録音日時・解析条件は変わらない。

## 種一覧の検出数と順序（2026-09-10）

## 音声の重複判定とクイズの図（2026-09-10）

- 音声はPath.resolve()で正規化した絶対パスで重複判定する。別のフォルダにある同名・同内容の音声は別ファイルとして登録できる。シンボリックリンクはリンク先の実体で判定する。内容のハッシュによる重複判定は行わない。
- クイズは回答前からスペクトログラムと再生を表示する。解答後と振り返りも同じ部品で表示し、追加の表示切替は不要。回答時・次問への移動時に前の音を止める。
- 正解の種名・元ファイル名は図のAPIに含めない。未来の問題の図は取得できず、現在と回答済みの問題だけを表示する。
- 確認結果：回帰検査12件成功、型チェック0 errors / 0 warnings。Mac .appでテスト用3問を完了し、回答前の図、再生、回答時の停止、24秒→12.9秒→25秒の次問切替、振り返りでの図と音の切替を確認。通常データの成績は変更していない。初回の図の待ち時間は従来の課題として残る。

### 種ごとの確認の流れ（2026-09-30 追記）

[種ごとの確認の流れ](species-flow-proposal-2026-09-30.md)の実装を、合成データの地点（6日分、BirdNET・Perch）で
ブラウザ（1280×800、日本語。英語は種のページのみ）から通しで確認した。Macアプリ・Windowsでは未確認。

- 種のページ：見出しは種名、2つのカード（いるか／いつ・どれくらいか）で最初に押すボタンがわかる。戻る操作は「種の一覧に戻る」。
  モデルごとの状態は「まだ確かめていません」「① 基準を決めている途中（a/b）」「目標に届いた（正しさ p、目標 t）」などの文で示し、色だけに頼らない。
- ［いるか］：上から順の一覧、各行にスペクトログラム・再生・「この種の声だ」。ダブルクリックでその位置から再生。押すと状態が「聞いて確認できた（根拠の音 n）」に変わり、押し直すと取り消せる。
  2音を再生すると「上位2音を聞きました。」と表示し、「確認できなかったと記録する」で記録した。表示件数と再生済みの音は戻っても保たれる（sessionStorage）。
- ［いつ・どれくらいか］：BirdNETの①20音→②（評価日の基準以上が15区間のため15音）→完了表示を確認。Perchの①は、BirdNETで答えた9音が回答済みの状態で始まった。
  ①完了後に「次へ：② 正しさを確かめる」、完了後は「種の結果へ戻る」が主ボタン。確認の削除は確認文を出してから行う。
- 検索（旧C3〜C5を置き換え）：種は1つ。検索が終わると［いるか］の検索結果一覧へ移る。同じ種の2回目は「すでに検索しています…削除してから」と種の結果へのリンクを表示する。
  種のページの削除では、消えるもの（材料の判定6件、種のモデルとその確認1個）を列挙してから削除した。
- 種のモデル：検索結果に「声あり／声なし」を付け、各3音で「モデルを作る」が有効になり、作成後に一覧と「精度を確かめる」が出る。
- レポート（F1）：種ごとのまとめの表が「いるか」「いつ・どれくらいか」の2列。確かめていないモデルも「既定値（確かめていない）」と明記して載る。

  「この種の声だ」を押した状態が無効に見えた（強調表示を修正）。
